# Manual test checklist

- [ ] Contract compiles
- [ ] Local Hardhat node starts on 127.0.0.1:8545
- [ ] Contract deploys successfully
- [ ] Frontend shows Blockchain Connected
- [ ] Valid reward can be stored
- [ ] Same Employee ID can be retrieved
- [ ] Employee Name and Reward Points are displayed correctly
- [ ] Empty Employee ID is rejected
- [ ] Empty Employee Name is rejected
- [ ] Zero reward points are rejected
- [ ] Duplicate Employee ID is rejected
- [ ] Unknown Employee ID shows not found
- [ ] Blockchain Records table lists stored records
